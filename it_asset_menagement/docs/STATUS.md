# สถานะโปรเจค — IT Asset Management

อัปเดตล่าสุด: 22 ต.ค. 2026

## ตรวจระบบรอบ 22 ต.ค. 2026

### แก้แล้ว (ยังไม่ขึ้นระบบจริง — รอสั่ง deploy)

- กฎฐานข้อมูล: พนักงานแก้ข้อมูลส่วนตัวได้เฉพาะของตัวเอง (เดิมแก้ M365 Email/รหัสผ่านของคนอื่นได้)
- กฎฐานข้อมูล: ส่งคำขอ (แจ้งซ่อม/เบิก/เปลี่ยนเครื่อง/อุปกรณ์เสริม) ได้เฉพาะในชื่อตัวเอง
- `api/staff-first-setup`: เลิกอ่านพนักงานทั้งบริษัททุกครั้งที่กด (กินโควตา)
- รายชื่อพนักงานที่ไม่มีวันที่สร้าง เรียงลำดับผิด (ค่า NaN)
- อัปเดต library ที่มีช่องโหว่ระดับร้ายแรง (critical หมดแล้ว)

### ยังค้าง — เรียงตามความสำคัญ

| # | ระดับ | เรื่อง | ต้องทำอะไร |
|---|---|---|---|
| 1 | สูงมาก | พนักงานทุกคนที่ login อ่านรหัสผ่าน M365 ของทุกคนได้ (อยู่ในเอกสาร `employees`) | ย้าย `m365Password` ไปเก็บแยกที่ให้อ่านได้เฉพาะ admin + เจ้าของ ต้องย้ายข้อมูลจริง |
| 2 | สูงมาก | ถ้า Firebase เปิดให้สมัครบัญชีเองได้ ใครก็สร้างบัญชีแล้วอ่านข้อมูลทั้งระบบได้ | เจ้าของเช็ค Firebase Console → Authentication → Settings → User actions → ปิด "Enable create (sign-up)" · แต่ต้องย้ายการสร้าง admin (`UserManagementPage`) ไปทำผ่าน API ก่อน ไม่งั้นสร้าง admin ไม่ได้ |
| 3 | สูง | รหัสผ่านเริ่มต้นพนักงาน = รหัสพนักงาน และ login ลองผิดได้ไม่จำกัด | บังคับเปลี่ยนรหัสครั้งแรก + จำกัดจำนวนครั้งที่ลองผิด |
| 4 | กลาง | เก็บรหัสผ่านพนักงานแบบอ่านออก (`staff_passwords.plaintext`) ให้ admin ดู | ตัดสินใจเชิงนโยบาย — แนะนำเลิกเก็บ ใช้ "รีเซ็ต" แทน "ดู" |
| 5 | กลาง | "จดจำฉัน" เก็บรหัสผ่านในเบราว์เซอร์ (base64 ถอดได้) | เปลี่ยนเป็นจำแค่รหัสพนักงาน |
| 6 | กลาง | ผู้ที่ login ลบรูปประเมินสภาพของใครก็ได้ (`storage.rules`) | จำกัดการลบเป็น admin |
| 7 | กลาง | ช่องโหว่ใน library ที่เหลือ: `xlsx` (ยังไม่มีเวอร์ชันแก้) · `firebase-admin` 12 → ต้องขึ้น 13 | อัปเกรด firebase-admin แล้วทดสอบ API ทั้งหมด · `xlsx` เปลี่ยนเป็น `exceljs` |
| 8 | ต่ำ | lint ค้าง 99 จุด (ส่วนใหญ่ตัวแปรไม่ใช้ / setState ใน effect) | เก็บกวาดเป็นงานแยก |
| 9 | ต่ำ | ไฟล์หลักใหญ่ (index ~980KB, KpiDashboard ~890KB) โหลดช้าบนเน็ตช้า | แยกโหลดเฉพาะหน้า |
| 10 | ต่ำ | แทบไม่มีเทสต์อัตโนมัติ และเครื่องนี้ไม่มี Java จึงรัน emulator ทดสอบกฎไม่ได้ | ติดตั้ง Java + เขียนเทสต์กฎฐานข้อมูล |
