## ย้ายรหัส M365 ขึ้นระบบจริง (ทำครั้งเดียว ตามลำดับ)

รหัส M365 ย้ายจาก `employees` ไปเก็บที่ `employee_secrets` ซึ่งเปิดได้แค่ admin กับเจ้าของรหัส
ทดสอบบน emulator ครบแล้ว: สิทธิ์ 18 ข้อ · สคริปต์ย้าย (ย้าย / ไม่ทับของใหม่ / รันซ้ำได้) · หน้า admin ดู-แก้ · หน้าพนักงานดู-แก้

**ขั้น 1-2 ต้องทำติดกัน** — กฎใหม่กับโค้ดใหม่ต้องขึ้นพร้อมกัน ไม่งั้นระหว่างนั้นบันทึกรหัส M365 ไม่ได้

1. ขึ้นกฎฐานข้อมูล: `firebase deploy --only firestore:rules`
2. ขึ้นโค้ดหน้าเว็บ: `git push` (Vercel deploy เอง) — ถ้าผ่านไปแล้ว รหัสยังแสดงได้ตามปกติ เพราะโค้ดใหม่อ่านค่าเก่าได้ระหว่างรอย้าย
3. เตรียมกุญแจ: Firebase Console → Project settings → Service accounts → Generate new private key → เก็บไฟล์ไว้นอกโฟลเดอร์โปรเจค
4. ดูก่อนว่าจะย้ายอะไร (ยังไม่เขียน):
   ```
   $env:GOOGLE_APPLICATION_CREDENTIALS="C:\path\ไฟล์กุญแจ.json"
   npm run migrate:m365
   ```
5. ย้ายจริง: `npm run migrate:m365 -- --apply` → สรุปท้ายต้องเป็น "ลบฟิลด์เดิมแล้ว N" เท่ากับจำนวนที่เจอ
6. ตรวจ: รันข้อ 4 ซ้ำ ต้องขึ้น "ย้าย 0" · เปิดหน้าพนักงานสักคนในระบบ admin ต้องยังเห็นรหัส M365
7. ลบไฟล์กุญแจทิ้ง

ย้อนกลับ: ต้องถอยทั้งโค้ดและกฎพร้อมกัน (revert commit นี้แล้วทำข้อ 1-2 ใหม่) · ข้อมูลไม่หาย —
สคริปต์คัดลอกไปที่ใหม่และลบที่เดิมในคำสั่งเดียวกัน แต่ถ้าถอยหลังข้อ 5 โค้ดเก่าจะมองไม่เห็นรหัส (อยู่ที่ `employee_secrets`) จนกว่าจะขึ้นโค้ดใหม่อีกครั้ง
