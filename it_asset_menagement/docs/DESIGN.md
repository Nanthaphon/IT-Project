# IT Asset Management — UX/UI Design

ธีม **v4 "Harbor"** — ฟ้าทะเลเข้ม (teal) โทนเย็น สะอาด อ่านง่าย
ค่าทั้งหมดในไฟล์นี้ตรวจจากโค้ดจริง (`src/index.css`, `src/ui/earth.js`) เมื่อ 9 พ.ย. 2569

> ไฟล์คู่กัน: `DESIGN-SYSTEM.md` = วิธีย้ายชุด UI ไปโปรเจคอื่น · `CLAUDE.md` หัวข้อ Design System = กฎสำหรับนักพัฒนา

## 3. ตัวอักษร

**ฟอนต์:** Bai Jamjuree (Google Fonts) ทั้งระบบ — ไทยและอังกฤษกลมกลืนกัน

**ขนาด — ใช้ได้ 9 ค่าเท่านั้น**

| คลาส | px | ใช้กับ |
|---|---|---|
| `text-[10px]` | 10 | ป้ายจิ๋วในตาราง/ชิป |
| `text-[11px]` | 11 | คำอธิบายย่อย หน่วย |
| `text-xs` | 12 | หัวตาราง badge meta |
| `text-[13px]` | 13 | ป้ายกำกับฟอร์ม ข้อความรอง |
| `text-sm` | 14 | **เนื้อความหลัก** ปุ่ม |
| `text-[15px]` | 15 | หัวข้อย่อย |
| `text-[19px]` | 19 | หัวข้อหน้าต่าง (modal) |
| `text-[22px]` | 22 | หัวข้อหน้า |
| `text-3xl` | 30 | ตัวเลขเด่นในการ์ดสถิติ |

**น้ำหนัก — 2 ค่า:** `font-normal` (เนื้อความ) · `font-medium` (เน้น) — ห้าม `semibold/bold/black`
ความเด่นมาจาก **สี** (`stone-900`) ไม่ใช่ความหนา

**ภาษาไทย:** ห้ามตัดกลางคำ · ห้าม `tracking-wide` / `uppercase` · ตัวเลขในตารางใช้ `tabular-nums`
**วันที่:** DD/MM/YYYY ทั้งระบบ (`utils/formatDate.js`)

## 5. คอมโพเนนต์

### ปุ่ม

| ชนิด | หน้าตา | ใช้เมื่อ |
|---|---|---|
| หลัก | พื้น `clay-600` ตัวขาว · hover `clay-700` | การกระทำหลัก 1 ปุ่มต่อพื้นที่ (เพิ่ม บันทึก) |
| รอง | พื้นขาว ขอบ `stone-200/60` ตัว `stone-600` | ยกเลิก ส่งออก ตัวกรอง |
| อันตราย | พื้น `brick-600` ตัวขาว | ยืนยันลบ (ห้ามใช้แดงนีออน `rose-600`) |
| ไอคอน | สี่เหลี่ยม 36px ไม่มีพื้น · hover `stone-100` | เมนู ⋯ ปิด |

### ฟอร์ม
- ป้ายกำกับ `text-[13px] font-medium text-stone-500` อยู่เหนือช่อง
- ช่องกรอก `rounded-xl` โฟกัสแล้วมีวง `ring-2 ring-clay-600/15`
- **ช่องเลือก (บริษัท แผนก ตำแหน่ง แบรนด์ ฯลฯ) เลือกจากรายการเท่านั้น** — เพิ่มตัวเลือกที่ ตั้งค่า → ตัวเลือกฟิลด์
- เลือกได้หลายค่า (แบรนด์ที่ดูแล) = ชิป `clay-50` กด × เอาออก

### ตารางรายการ (`ListPage`)
- หัวตาราง `text-xs font-medium text-stone-400` ไม่มีพื้น ไม่ใช้ตัวพิมพ์ใหญ่
- แถวบนสุด: ช่องค้นหา (ซ้าย) · ตัวกรอง / ส่งออก / ปุ่มหลัก (ขวา)
- ตัวกรองเลือกได้หลายค่า จำค่าไว้ข้ามการเปิดหน้า (ต่อหน้า ไม่ปนกัน)
- ติ๊กเลือกแล้วมีแถบการกระทำกลุ่ม (ส่งออกที่เลือก ลบที่เลือก)
- เมนู ⋯ ท้ายแถว ลอยเหนือตาราง เปิดขึ้นบนเมื่อชิดขอบล่าง

### ป้ายสถานะ
`rounded-lg` · พื้นอ่อน · ไม่มีขอบ · `text-xs font-medium` · มีจุดสีหรือไอคอนนำหน้าได้

### หน้าต่าง (modal) / กล่องยืนยัน
- มุม `rounded-lg` · หัว/ท้าย `px-7 py-5` · หัวข้อ 19px
- ปุ่มท้าย: รองซ้าย หลักขวา
- **ข้อความยืนยันต้องบอกผลจริง** — เช่น ลบพนักงาน = "ยังเห็นในหน้าพนักงาน (สถานะ ออกแล้ว) กู้คืนได้" ไม่ใช่ "ย้อนกลับไม่ได้"

### Sidebar
- พื้นไล่สี `#1A414C → #12303A` · ตัวอักษรขาว 85% · เมนูที่เลือกพื้นขาว 15% มีจุดขาว
- ตัวเลขค้าง: แดงอ่อน = รอดำเนินการ · ฟ้าอ่อน = ใกล้หมดอายุ
- กลุ่ม: ทรัพย์สิน → การจัดการ → รายงาน → **ตั้งค่า** (พับ/กางได้: ตัวเลือกฟิลด์ · จัดการผู้ใช้ · เปลี่ยนรหัสผ่าน)

## 7. หลัก UX

| หลัก | ตัวอย่างในระบบ |
|---|---|
| **เห็นปัญหาโดยไม่ต้องหา** | ยืมเลยกำหนด = แถวแดง + ชิปกรอง "เลยกำหนดคืน" · License ใกล้หมด = ป้ายในรายการ ใบคลุม และรายงาน |
| **ไม่ซ่อนข้อมูล ใช้ตัวกรองแทน** | พนักงานที่ออกแล้วอยู่ในหน้าเดียวกัน กรองด้วยสถานะ (ไม่มีถังขยะแยก) |
| **ลดการพิมพ์ ลดพิมพ์ผิด** | เลือกจากรายการ · นำเข้าหัวหน้าด้วยรหัสพนักงาน · template Excel มี sheet อ้างอิงให้ลอก |
| **ทำซ้ำได้เร็ว** | ปุ่ม "ทำซ้ำ" ทรัพย์สิน · ตัวกรองจำค่าไว้ |
| **บันทึกอัตโนมัติ** | รายงานประจำเดือน ใบคลุม ตัวเลือกฟิลด์ — บอกสถานะ "กำลังบันทึก / บันทึกแล้ว" |
| **ย้อนได้** | ลบพนักงาน = ย้ายเป็น "ออกแล้ว" กู้คืนได้ · ลบถาวรต้องยืนยันอีกชั้น |
| **ข้อความสั้น** | 1 ประโยคพอ · ไม่อธิบายซ้ำสิ่งที่หน้าจอบอกอยู่แล้ว |
| **บอกทางเมื่อทำไม่ได้** | ช่องเลือกไม่มีตัวเลือก → "เพิ่มได้ที่ ตั้งค่า → ตัวเลือกฟิลด์" · นำเข้ารหัสหัวหน้าไม่เจอ → บอกแถวที่ผิด |

## 8. ทำ / ไม่ทำ

| ✓ ทำ | ✗ ไม่ทำ |
|---|---|
| ใช้คลาส token (`clay-*` `olive-*` `stone-*` …) | hardcode สี (`#A65F3C`, `#1E487A`, `emerald-*` = ของค้างจากธีมเก่า) |
| `font-medium` + สีเข้มเพื่อเน้น | `font-semibold` / `font-bold` |
| หน้าเต็มความกว้าง | `max-w-*` + `mx-auto` |
| modal `rounded-lg` | modal `rounded-2xl` |
| ป้ายสถานะพื้นอ่อนไม่มีขอบ | pill กลม มีขอบ ตัวหนา |
| ขนาดตัวอักษร 9 ค่าในตาราง | ค่าครึ่งพิกเซล (`text-[12.5px]`) |
| lucide `strokeWidth={2}` | emoji / svg เขียนมือ / เส้นหนาหลายค่า |
